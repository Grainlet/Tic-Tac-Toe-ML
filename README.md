# How it works?
During each training generation, a population of neural networks competes across simulated Tic Tac Toe matches. Each network receives 9 board inputs representing its own marks, the opponent’s marks and empty spaces, then outputs scores for the possible moves. Networks are rewarded for winning and drawing while losses receive lower scores. Each generation, the highest-performing networks are preserved, crossed over and mutated to create the next population. Over successful generations, the AI evolves its move selection, and the best performing network is saved for players to fight against.
